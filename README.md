# SafeProducts

Build a complete product safety search website called 
SafeProducts for Indian consumers. This platform checks 
whether cosmetics, health supplements, nutraceuticals, 
probiotics, and food for special dietary use are safe.

MOBILE RESPONSIVE
═══════════════════════════════
Full mobile responsive throughout.
Profile pills: 2x2 grid on mobile.
Category cards: 2 columns on mobile.
Expert cards: stack vertically on mobile.
Search bar: full width on mobile.
Product cards: single column on mobile.                                                                                                 -- Run in Supabase SQL Editor first

CREATE TABLE IF NOT EXISTS public.page_views (

  id bigint generated always as identity primary key,

  page text,

  search_term text,

  category_clicked text,

  profile_used text default 'ALL',

  session_id text,

  device_type text,

  visited_at timestamptz default now()

);

CREATE INDEX IF NOT EXISTS idx_pageviews_date

ON public.page_views USING btree (visited_at DESC);

CREATE INDEX IF NOT EXISTS idx_pageviews_search

ON public.page_views USING btree (search_term);

-- RLS: allow insert from anyone, 

-- read only for admin

ALTER TABLE public.page_views 

ENABLE ROW LEVEL SECURITY;

CREATE POLICY "public can log views"

ON public.page_views FOR INSERT

WITH CHECK (true);

CREATE POLICY "admin reads analytics"

ON public.page_views FOR SELECT

USING (auth.role() = 'authenticated');
